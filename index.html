Как опубликовать любой HTML-файл через GitHub Pages и получить ссылку, которая открывается на iPhone, Android и компьютере
Результат: https://ваш-логин.github.io/название
5 шагов · займёт 5 минут
1
Создайте аккаунт на GitHub
Если аккаунта ещё нет — зарегистрируйтесь. Если есть — войдите.
Зайдите на github.com → нажмите «Sign up» → введите email, пароль, имя пользователя → подтвердите email
💡 Имя пользователя войдёт в вашу ссылку. Например логин «techno-holding» даст ссылку techno-holding.github.io/...
2
Создайте новый репозиторий
Репозиторий — это папка на GitHub, где хранится ваш файл.
Нажмите «+» в правом верхнем углу → «New repository»

Заполните:
• Repository name — название без пробелов (например: kniga-proraba)
• Description — описание (необязательно)
• Выберите «Public» (обязательно!)
• Поставьте галочку «Add a README file»

Нажмите зелёную кнопку «Create repository»

3
Загрузите HTML-файл и назовите его index.html
Это главное правило — файл должен называться именно index.html, иначе GitHub Pages не поймёт что показывать.
Способ 1 — переименуйте на компьютере до загрузки:
Правая кнопка мыши на файл → «Переименовать» → index.html

Способ 2 — переименуйте на GitHub после загрузки:
Нажмите на файл → иконка карандаша ✏️ → сотрите название → введите index.html → Commit changes
Для загрузки: нажмите «Add file» → «Upload files» → перетащите файл → нажмите «Commit changes»
kniga-proraba / файлы
📄 README.md первоначальная фиксация
🌐 index.html ✓ правильное название
⚠️ Если файл называется иначе (например kniga.html) — ссылка выдаст ошибку 404. Только index.html!
4
Включите GitHub Pages
Это превращает репозиторий в настоящий сайт с публичной ссылкой.
1. Нажмите вкладку «Settings» (шестерёнка вверху страницы репозитория)
2. В левом меню найдите и нажмите «Pages»
3. В разделе «Branch» выберите «main»
4. Рядом выберите папку «/ (root)»
5. Нажмите «Save»

💡 После нажатия Save подождите 2–3 минуты. GitHub собирает сайт — это занимает немного времени.
5
Получите и проверьте ссылку
Обновите страницу Settings → Pages — появится зелёная плашка с вашей ссылкой.
Ссылка формируется автоматически по шаблону:

https://[ваш-логин].github.io/[название-репозитория]

Например: https://ekaterinathld-arch.github.io/kniga_proraba
Settings → Pages

Как обновить книгу, если изменились регламенты
Обновление файла — 3 шага
1
Зайдите в репозиторий на github.com → нажмите на файл index.html
2
Нажмите иконку карандаша ✏️ (Edit) → в правом верхнем углу нажмите «...» → «Delete file» — удалите старый. Затем через «Add file → Upload files» загрузите новый index.html
3
Нажмите «Commit changes» — через 1–2 минуты ссылка обновится автоматически. Все кто откроют её увидят новую версию
Полезные советы
📱
Для iPhone
Открывать ссылку только в Safari — другие браузеры на iOS могут работать некорректно
🔗
Отправка прорабам
Отправьте ссылку в Telegram или WhatsApp — они нажмут и откроется как обычный сайт
⏱️
Задержка
После загрузки нового файла подождите 2–3 минуты — GitHub обновляет сайт не мгновенно
🆓
Бесплатно
GitHub Pages полностью бесплатный. Никаких лимитов на количество просмотров
🔒
Публичный доступ
Ссылку может открыть любой. Если нужна защита — добавьте пароль через JavaScript внутри файла
📋
Один файл
Вся книга прораба — один HTML-файл. Менять нужно только его, остальное GitHub делает сам
